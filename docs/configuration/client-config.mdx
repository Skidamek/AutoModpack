# Client configuration

`automodpack/client-config.json` in the game directory of the instance. The file is created on the first start with defaults.

## Editing the file

- Restart the game after editing, unless a note below says otherwise.
- Invalid JSON stops the launch with the reason in the log. Unknown keys are ignored and logged.
- Leave `DO_NOT_CHANGE_IT` alone. It marks the file version for future migrations.

| Setting | Default | Description |
|---|---|---|
| `selectedModpackId` | `""` | Which pack this instance follows. AutoModpack manages this value; it is the stable seven-character id the server generated once, and it survives display-name and address changes. |
| `updateSelectedModpackOnLaunch` | `true` | Fetches and applies the selected pack during launch, before the game loads it. When false, launch loads the current state and contacts the server only when you join. See [client updates](../how-it-works/client-updates). |
| `selfUpdater` | `false` | Checks Modrinth on its own for AutoModpack updates. Turning this off does not affect modpack installs. |
| `syncAutoModpackVersion` | `true` | Matches the AutoModpack version the server runs, updating or downgrading from Modrinth as needed. |
| `syncLoaderVersion` | `true` | Matches the modloader version the server publishes. Applies on Prism, MultiMC forks, and Pandora; see [launcher compatibility](../compatibility/launchers#loader-version-sync). |
| `playMusic` | `true` | Plays music while a download runs in-game. |
| `showModpackSettingsButton` | `true` | Shows the "Modpack settings" button, where players pick optional [groups](server-config#groups). |
| `pinnedModIds` | `[]` | Mod ids this instance always loads from its own `mods` folder. See below. |

## Pinned mods

A player who wants to run their own version of a mod adds its id to `pinnedModIds`. AutoModpack still syncs the pack's copy into the managed storage but does not load it, so the instance's own jar wins.

Matching covers `modId` and `provides`. A pin with no matching jar does nothing. The pack may genuinely need the version it ships, so a pin can break a pack; that is between the player and the pack. Restart to apply changes.
