AutoModpack syncs the server's modpack to every player automatically. The server publishes a pack; clients verify it, download it, and follow every change you publish. Mods, configs, resource packs, and shader packs all travel the same way.

Start with the [quick start](docs/quick-start). It covers installing the mod on a server and connecting with a client.

From there:

- [Building the modpack](docs/pack-content) explains what gets synced and where to put your own content.
- [Server configuration](docs/configuration/server-config) and [client configuration](docs/configuration/client-config) document every setting.
- [Security](docs/security) explains how clients know a server is who it claims to be.
