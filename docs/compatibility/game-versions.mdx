AutoModpack ships one jar that covers every supported game version. The release page lists the exact files and game versions of the current release.

## Supported versions

| Minecraft | Loaders |
| --- | --- |
| 1.18.2, 1.19.2, 1.20.1 | Fabric, Forge |
| 1.21.1, 1.21.4, 1.21.5, 1.21.8, 1.21.10, 1.21.11 | Fabric, NeoForge |
| 26.1, 26.2, 26.3 | Fabric, NeoForge |

A server and its clients must run the same Minecraft version, as always. The AutoModpack jar itself is the same file everywhere; it detects the loader and game version at startup.

## Versions dropped in v5

v4.0.5 also supported 1.19.4 (Fabric, Forge), 1.20.4 and 1.20.6 (Fabric, NeoForge), and 1.21.3 (Fabric, NeoForge). v5 has no builds for them. Servers and players on those versions should stay on v4 or update the game.
