### Loader version sync

Before AutoModpack changes the loader version, it checks the Prism meta server. This check runs for all launchers.

If the meta server does not have the loader version, AutoModpack does not change the loader version. The game keeps the loader version that the launcher installed. This prevents launch failures like `Could not download metadata for NeoForge 21.1.249` on Prism and MultiMC forks.

Server owners can turn loader version syncing off with `syncLoaderVersion: false` in the server config. Then the server does not provide a loader version at all.
