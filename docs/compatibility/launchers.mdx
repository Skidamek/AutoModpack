## Loader version sync

When the server publishes a loader version, AutoModpack updates the loader on Prism, MultiMC forks, and Pandora. Other launchers manage the loader themselves, so the game keeps the version the launcher installed.

Before changing anything, AutoModpack asks the Prism meta server whether it knows the target loader version. If it does not, the loader is left alone rather than risk installing something the launcher cannot resolve. Server owners can stop publishing a loader version entirely with `syncLoaderVersion: false` in the [server config](../configuration/server-config).
