### Loader version sync

Works only on Prism/MultiMC/forks and Pandora launchers.

Before AutoModpack changes the loader version, it checks the Prism meta server.

If the meta server does not have the loader version, AutoModpack does not change the loader version. The game keeps the loader version that the launcher installed.

Server owners can turn loader version syncing off with `syncLoaderVersion: false` in the server config. Then the server does not provide a loader version at all.
