### Prism/MultiMC loader version sync

Prism (and MultiMC forks) must be able to download component metadata for the loader version the server publishes; otherwise the instance can stall or fail to launch with errors like "Could not download metadata for NeoForge 21.1.249". AutoModpack checks the Prism meta server before requesting a loader version change and skips the sync when the version is not available there, keeping the loader version already installed in the launcher. Server owners can also disable loader version syncing entirely with `syncLoaderVersion: false` in the server config.
