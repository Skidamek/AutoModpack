`/amp` is an alias for `/automodpack`.

- `/automodpack` - Status of automodpack and general help.
- `/automodpack generate` - Publish a generation when the content changed.
- `/automodpack generate notes <text...>` - Publish a generation with patch notes.
- `/automodpack generate preview [notes <text...>]` - Preview the next generation without publishing it.
- `/automodpack generate if-state <digest> [notes <text...>]` - Publish only when the current state matches the digest.
- `/automodpack generate history` - List the complete generation timeline and copyable generation IDs.
- `/automodpack generate revert <generation-id>` - Preview a server rollback.
- `/automodpack generate revert <generation-id> confirm [notes <text...>]` - Publish the selected old state as a new generation.
- `/automodpack generate storage` - Show a storage receipt for the journal and objects.
- `/automodpack generate storage collect confirm` - Delete every object the current generation does not serve. Older generations stay listed in the journal but their bytes die, so they can no longer be restored.
- `/automodpack host` - Status of modpack hosting.
- `/automodpack host start` - Start modpack hosting.
- `/automodpack host stop` - Stop modpack hosting.
- `/automodpack host restart` - Restart modpack hosting.
- `/automodpack host connections` - Lists all currently active modpack host connections.
- `/automodpack host fingerprint` - Get the [certificate fingerprint](../technicals/certificate) of the modpack host.
- `/automodpack host fingerprint dns <minecraft-hostname>` - Generate a DNSSEC record that lets clients authenticate the host's self-signed certificate automatically.
- `/automodpack host fingerprint share <minecraft-address>` - Generate plain and pinned copyable addresses without storing the fingerprint in Minecraft's server list.
- `/automodpack host bootstrap pin <origin>` - Write `automodpack/automodpack-bootstrap.exported.json` with a TLS pin. Copy it to clients as `automodpack/automodpack-bootstrap.json`.
- `/automodpack host bootstrap install <origin>` - Write an install export with the published pack, provisioning secret, and configured advertised endpoint.
- `/automodpack host bootstrap install <origin> <endpoint> <connection-mode>` - Same as install, with an explicit endpoint and connection mode.
- `/automodpack config reload` - Reload config files.

The journal is append-only and never compacted, so every published generation stays visible with its patch notes and metadata forever. `collect confirm` is the only storage command; it prints the receipt of the bytes it deleted, and every generation outside the current head becomes unrestorable.
