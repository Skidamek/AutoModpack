# Client local storage

The client keeps its own copy of every pack you sync. The storage screen ("Client local storage", reachable from the modpack manager) shows what that copy holds and offers two actions: Verify storage and Clean local storage.

## What is stored

Each pack's files live once in a content-addressed object store, keyed by SHA-1. On top of that sit the journal mirror (the server's generation timeline), the active projection the game loads from, baselines and overlays for editable files, notes, and preserved files. When two generations ship the same jar, the store holds one copy of the bytes and both generations point at it.

## History is never trimmed on its own

Every generation you synced stays downloadable-adjacent: its file data is kept so the History screen can restore it later. No schedule, no size limit, no automatic cleanup runs in the background. Storage grows until you clean it or remove the pack. Removing a pack reclaims its data through the normal removal flow.

## What Clean local storage does

Clean local storage is the one explicit cleanup pass. Per pack it keeps the active generation and the newest generation with all their file data, plus every generation's policy document, so the history list and its details keep working. It deletes the file data that only older generations still name. The journal mirror, the active projection, overlays, baselines, notes, and preserved files are untouched, so nothing about the running pack changes.

The History screen judges restorability by live checks against the object store, so a generation whose file data was cleaned shows as no longer restorable instead of failing halfway through a restore.

A clean refuses to run while an update transaction is active. After it finishes, the storage screen shows one receipt per pack: the date of the clean, the generation it cleaned through, and how much was reclaimed. Generations older than that boundary can no longer be restored on this computer. The receipt only appears after a clean ran on this installation.
