# Update review

AutoModpack always shows a review before it installs a first modpack, applies a changed generation, or switches between cached installed modpacks.

The review is part of the update contract. It lets the player inspect file changes and patch notes before the active files change. It is not a replacement for certificate verification, trust prompts, fingerprint mismatch handling, or warnings for untrusted certificates.

A future preference may be stored per installed modpack. There is no instance-wide client setting for bypassing review.
